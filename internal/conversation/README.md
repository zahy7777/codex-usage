# Conversation

Owns Codex rollout facts. `usage/` scans and attributes JSONL records; `store/` persists derived usage and metadata; `model/` defines usage facts; `timezone/` fixes accounting day boundaries. `ReadLedger` assembles canonical, deduplicated thread and turn usage, response calls, and on-demand visible messages. The caller supplies a thread ID; a turn ID plus offset and limit opts into transcript reads. Each visible message keeps log order and carries `response_id` only when a recorded response proves call ownership; tool results inherit the verified tool request's response. Legacy snapshots without response identity stay at turn level. Bodies never enter the statistics database. The server consumes the ledger result and does not parse JSONL.
