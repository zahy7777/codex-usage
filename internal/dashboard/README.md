# Dashboard

Owns the loopback application and presentation. `app/` runs CLI, Stop-hook notification, and service lifecycle; `server/` exposes local APIs; `web/` renders the three-level UI. `config/`, `platform/`, `updater/`, and `cliui/` support operation. `/api/v1/ledger` obtains canonical usage and on-demand public content from Conversation, then independent estimates from Pricing. `/api/v1/pricing/credits` manages local effective-date rates. Stop notifications trigger an incremental scan, while the periodic scan repairs missed notifications. JSONL decoding stays in Conversation.
